# Srishanth S — Portfolio

A stunning personal portfolio built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**, inspired by the VYRO AI Glasses futuristic design language.

## Design System

| Token | Value |
|-------|-------|
| Electric Blue | `#2000EA` |
| Lavender Purple | `#9E92E7` |
| Soft White | `#FFF8F8` |
| Cool Gray | `#8D8D8D` |
| Deep Black | `#1A0303` |

**Fonts:** Syne (display) · DM Sans (body) · DM Mono (code)

## Features

- 🎨 **Liquid Glass Morphism** — frosted glass cards with backdrop blur
- 🌊 **Particle Canvas** — animated floating particles with WebGL-style connections
- 💧 **Blob Animations** — organic liquid shape morphing
- ✍️ **Typewriter Effect** — cycling role titles
- 🖱️ **Custom Cursor** — magnetic ring cursor with blend modes
- 📜 **Marquee Ticker** — infinite skill scroll
- 🌟 **Scroll Reveal** — staggered IntersectionObserver animations
- 📱 **Fully Responsive** — mobile-first design
- ⚡ **Performance Optimized** — CSS-native animations

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
npm start
```

Open [http://localhost:3000](http://localhost:3000)

## Sections

1. **Hero** — Cinematic intro with particle field and typewriter
2. **Marquee** — Infinite tech stack ticker
3. **Work** — 3 featured projects with glass cards
4. **About** — Bio, education, and certifications
5. **Skills** — Categorized tech grid
6. **Experience** — Timeline with internship and education
7. **Contact** — Email copy + social links

## Customization

Update your personal details in:
- `components/Hero.tsx` — Name, headline, links
- `components/Work.tsx` — Projects array
- `components/About.tsx` — Bio and certifications
- `components/Skills.tsx` — Skill categories
- `components/Experience.tsx` — Work + education
- `components/Contact.tsx` — Social links

## Deployment

Deploy instantly to Vercel:

```bash
npx vercel
```
